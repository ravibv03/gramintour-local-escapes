# GraminTour Local Escapes

Build a complete Smart Local Tourism Business Portal called 'GraminTour'. It needs a Tourist Discovery view with filters for Homestays, Local Guides, and Cultural Workshops, interactive booking modals with date pickers, mock UPI payment confirmation, and a Host Dashboard tab showing earnings, incoming bookings, and an 'Add New Listing' form. Use clean Tailwind CSS with warm, natural tourism colors.
